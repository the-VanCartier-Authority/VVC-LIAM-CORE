# B03 · Ownership de VAOS

Issue #10, seguimiento #2. Base B01 (#9, `f5362170157dd102f890d3378450c7afd46733c9`) aporta UID verificado. Se priorizó frente a B02 para cerrar lectura cruzada y proporcionar propiedad de tareas a los futuros límites asíncronos. PR independiente apilado, sin merges.

Reproducción previa `c81c619`: dos usuarios con JWT válidos podían leer detalle, listado y telemetría ajenos. Tres subtests y el test padre fallaron. [Salida](evidence/b03-before.txt).

El ownerUid de cada tarea y registro de telemetría se asigna exclusivamente desde req.auth.uid, nunca del body. Detalle ajeno devuelve el mismo 404 que un ID inexistente. El listado filtra antes de tomar las últimas 20 tareas; la telemetría y sus estadísticas se calculan después de filtrar. La autoprueba de sistema usa propietario nulo y no se muestra como actividad de un usuario. El procesamiento asíncrono conserva al propietario verificado.

Tests con dos usuarios: UID forjado en body ignorado, detalle/listado/telemetría privados, stats sin actividad ajena y 21 tareas del segundo usuario no desplazan la tarea propia del primero. Suite completa 94 tests, instalación congelada, TypeScript, build y smoke local. JWT efímeros y fixtures; no servicios reales.

No se declara aislamiento de localStorage (B04), push (B05), cuotas (B02) o persistencia de tareas (I10). VAOS sigue en RAM. Las estimaciones/defaults de métricas quedan en D02, sin atribuirles medición nueva. Revisión independiente e integración pendientes.
