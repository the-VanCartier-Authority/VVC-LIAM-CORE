## Identidad técnica del proveedor (F18)

No hay dependencia Kokoro, pesos, vocoder, ONNX, WebGPU, descarga o inicialización de un modelo Kokoro. Los nombres speakKokoro/KOKORO_VOICES son etiquetas del producto. ## Prueba de proveedor real y límites

Con `hasGeminiKey:false` confirmado en `/api/config`, se solicitó `/api/tts` con es_mateo y texto técnico sintético sin datos personales. HTTP 200, `fallback:true`, `reason:NEURAL_TTS_UNAVAILABLE`, cero bytes de audio; tiempo total observado **5.097,49 ms (n=1)**. El servidor registró error de WebSocket Edge `ECONNREFUSED`. No se usó un servicio de inferencia de pago ni un token del usuario.

Esto demuestra la respuesta de fallback del servidor en **este entorno**, no una caída universal de Edge ni calidad deficiente de la voz. No se repitió el mismo fallo de conectividad con las otras cinco voces; comparten transporte. Gemini TTS no se llamó sin clave. Pronunciación, naturalidad, clipping, acento, MOS, HD/Ultra-HD y latencia de primera respuesta audible quedan **NO EVALUABLES**. No se ha producido audio con el que sostener tales calificativos.

## TTS: flujo, timeouts y cancelación (F19)

- Edge solicita MP3 mono 24 kHz / 48 kbit/s, bufferiza el stream completo y devuelve base64 en JSON. Gemini solicita AUDIO y envuelve PCM en WAV 24 kHz, mono, 16 bit si no hay RIFF. Son parámetros de formato, no prueba perceptual de HD. [server.ts:264](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/server.ts#L264), [server.ts:273](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/server.ts#L273), [server.ts:374](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/server.ts#L374).
- Hay un timeout Edge de 7 s después de setMetadata; la configuración previa no queda dentro de ese timer. Gemini hace hasta cinco intentos de modelo con Promise.race de 6 s cada uno, sin abortar generación anterior. No se ha validado la disponibilidad de cada ID de TTS. [server.ts:264](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/server.ts#L264), [server.ts:269](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/server.ts#L269), [server.ts:355](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/server.ts#L355).

Caché RAM sin partición por usuario; clave incluye texto completo. ## STT y capacidades políglotas

STT usa SpeechRecognition/webkitSpeechRecognition del navegador, sin servidor de transcripción propio ni modelo local. Continuo, resultados intermedios y debounce de 1,5 s. Comprueba micrófono y devuelve mensajes para permisos/errores. [src/utils/speech.ts:119](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/src/utils/speech.ts#L119), [src/utils/speech.ts:178](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/src/utils/speech.ts#L178), [src/utils/speech.ts:230](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/src/utils/speech.ts#L230).

La configuración **fuerza español** si navigator.language no empieza por es. Una simulación en-US produjo recognition.lang=es-ES. No hay detección automática de idioma del audio ni selector STT multiidioma. El catálogo TTS tiene 12 perfiles y sólo dos etiquetas de idioma: Español/English. El idioma TTS depende del perfil, no del texto detectado. Los prompts de chat piden español. [src/utils/speech.ts:203](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/src/utils/speech.ts#L203), [src/utils/speech.ts:436](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/src/utils/speech.ts#L436), [src/App.tsx:1065](https://github.com/the-VanCartier-Authority/VVC-LIAM-CORE/blob/2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7/src/App.tsx#L1065).

## Offline y compatibilidad

Chromium 154 en Linux ejecutó UI offline después de cachear; no se usó micrófono real ni se probó Safari/Firefox/Android/iOS. Web Speech Recognition depende del navegador/proveedor y puede usar red; no hay descarga de STT offline ni detección de esa capacidad. SpeechSynthesis depende de voces disponibles, algunas online. No puede afirmarse voz offline garantizada. La función speakKokoro intenta servidor incluso con navigator.onLine=false; se comprobó en mock.
