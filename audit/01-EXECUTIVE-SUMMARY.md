# Diagnóstico ejecutivo de VVC LIAM CORE

> Auditoría independiente · 2026-10-23 UTC · `main@2ffadf44c2c09bbc8dcde47046ee7d5c08a039f7` · rama `audit/codex-deep-review`. Evidencia del código fijada a ese SHA; no se cambió código funcional.

**Dictamen: CRITICAL REMEDIATION REQUIRED. Preparación demostrada: 26,6/100 (27/100 redondeado).**

Existe una aplicación React/Express que compila, arranca en Node 24 y permite acciones locales y transporte LLM. No existe evidencia para describirla como un asistente autónomo, políglota, Zero-Knowledge y nativo listo para producción. Hay fallos demostrados de límites de confianza, respuestas simuladas de éxito y funciones desconectadas. La gravedad del dictamen depende de los riesgos confirmados, no de que falten credenciales para probar servicios externos.

## Qué se ha demostrado

- `bun install --frozen-lockfile` con Bun 1.4.4 instaló 664 paquetes sin cambiar el lockfile. `npm run lint` y `npm run build` pasaron. El script llamado lint es únicamente comprobación de TypeScript, no un analizador de seguridad o de estilo.
- `npm start` en producción y `npm run dev` sirvieron HTTP local en Node 24.19.0. `node server.ts` falla en Node 20.19.0 con `ERR_UNKNOWN_FILE_EXTENSION`.
- Chromium 154 cargó la interfaz sin excepciones de página, creó una tarea local y recargó la aplicación offline con caché previamente calentada. Esto no demuestra arranque offline en frío ni voz offline.
- La selección visual de Qwen se envió realmente al proxy NVIDIA y una petición HTTP a un proveedor local de prueba conservó el identificador solicitado. La selección de la barra se perdió al recargar.
- El parser reconoce órdenes españolas comunes; la detección local de solapamiento de eventos funciona para el caso probado. AES-GCM/PBKDF2 cifró y descifró una muestra y rechazó una contraseña incorrecta.
- Se ejecutaron 35 comprobaciones aisladas, más pruebas HTTP y de navegador. Que una comprobación pase puede significar que **reproduce un defecto**, no que la funcionalidad esté correcta. Los adaptadores Gmail, Calendar, Docs/Drive y People se ejercitaron exclusivamente con mocks para sus escrituras.

## Alcance, protección de datos y entrega

Se inspeccionaron los 78 archivos versionados; 54 archivos TS/TSX/JS suman 22.646 líneas. Las auditorías previas de `.gmp_cache/` se inventariaron, pero no se aceptaron como evidencia. No se editaron dependencias, lockfiles ni código funcional. Los scripts diagnósticos se ejecutaron en `/tmp` y se incluyen dentro de [07](07-TEST-RESULTS.md) para reproducirlos sin añadir código al producto.

No se utilizaron LLM de pago, OAuth del usuario ni recursos Google reales de escritura. La prueba remota de Edge usó texto sintético, sin clave Gemini de respaldo, y falló por `ECONNREFUSED`. No se imprimen credenciales ni datos personales en estos informes. No es una búsqueda forense completa de secretos en todo el historial Git: se revisó el árbol auditado y el padre para la migración.

Los nueve informes completan inventario, motores, Google, voz, seguridad, pruebas, plan y matriz. Las recomendaciones diagnósticas están en [08](08-REMEDIATION-ROADMAP.md); no se implementó ninguna corrección.
